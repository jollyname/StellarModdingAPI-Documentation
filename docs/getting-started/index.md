# Getting Started

This section will guide you through creating your first StellarDrive mod using the StellarModdingAPI.

Before creating mods, make sure you have the required tools installed:

- StellarDrive installed
- MelonLoader installed
- Visual Studio 2022
- The StellarDrive Mod Template

If you have not installed MelonLoader yet, start here:

[Installing MelonLoader](installing-melonloader.md)

Once your environment is ready, continue with:

[Creating Your First Mod](creating-your-first-mod.md)
