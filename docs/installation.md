# Installation

## Requirements

Before creating mods, make sure you have:

- StellarDrive installed
- StellarModdingAPI installed
- A code editor

## Installing the API

1. Download the latest version of StellarModdingAPI.
2. Extract it into your StellarDrive directory.
3. Launch StellarDrive.
